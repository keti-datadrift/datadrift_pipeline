# 비케이브 AI 재레이블링 및 드리프트 실험

## 목적과 고정 조건

기존 레이블을 문자열로 변환한 데이터 대신, 두 출처의 이미지를 같은 독립 교사가 직접 판독한 의사 레이블로 다시 학습합니다. 무신사 1,000장과 GS SHOP 651장 모두 대상입니다. 기존 이미지·분할·레이블 버전·모델은 변경하지 않습니다.

- 교사: 로컬 `gemma-4-12B-it` 기본 모델, 어댑터 없음. Qwen 학생과 독립된 모델입니다.
- 이미지와 기존 대분류(상의/아우터/하의/ACC)만 입력하며 기존 속성 정답·상품명·출처는 프롬프트에 넣지 않습니다. 대분류 자체는 재분류하지 않습니다.
- 비케이브 엑셀의 카테고리별 허용값을 직접 제공하고 greedy 생성, 최대 384 토큰, 이미지 최대 변 768, 배치 16을 사용합니다.
- 출력의 완전한 JSON 코드펜스만 제거해 파싱합니다. 원문은 그대로 보존합니다. 부적합 단일 값은 unknown, 부적합 디테일 배열은 빈 배열로 저장하고 해당 필드를 제외합니다. 기존 정답으로 대체하거나 임의로 유사한 값에 매핑하지 않습니다.
- 생산처와 정확한 SKU 색상 코드는 이미지에서 확정하지 않으므로 unknown/제외입니다. 비적용 속성도 손실·점수에서 제외합니다.
- AI 출처·원문·허용값 검사·기존 값·프롬프트 및 엑셀 해시를 저장하며 사람 검토 완료로 표시하지 않습니다.

## 학습 및 비교

사전에 고정한 시드 42와 학습률 2e-5, 각 100 optimizer steps로 Qwen3.5-2B와 4B를 기본 모델에서 새로 학습합니다. 전체 1 epoch가 아닙니다. 이전 100스텝 모델도 같은 새 정답으로 다시 평가하여, 서로 다른 정답 기준의 점수를 직접 비교하지 않습니다.

4B는 추가로 무신사만 학습하는 100스텝 대조군을 만듭니다. 두 출처 혼합 학습과 업데이트 예산을 맞춥니다. 이 비교는 출처 구성에 대한 탐색이며 전체적인 모델 우열이나 최적 학습 전략을 결정하지 않습니다.

평가에는 기존 validation에서 출처별 32개씩, 동일한 64개를 사용합니다. 원래의 train/test 분할은 유지하고 테스트 분할은 사용하지 않습니다. 출력 오류도 보존합니다. 교사와의 일치도이며 사람 검증 정답 정확도가 아닙니다.

## 드리프트 분석

- 원본 출처 사이 속성 JS divergence(base 2, 0~1)와 기존 이미지 RGB 분포를 비교합니다. 효과 크기 경보 임계값은 0.1입니다.
- 레이블별 999회 순열 검정과 BH 다중비교 보정을 제공합니다. `q_value`는 전체 속성, `category_adjusted_q`는 카테고리 내 비교 결과의 별도 검정군에서 계산합니다.
- 카테고리별 양쪽 유효 표본이 각각 10개 이상인 구간에서 JS를 계산하고, 양쪽 표본 수의 최솟값을 가중치로 사용합니다. 카테고리 내 순열도 같은 구간에서 시행합니다.
- 같은 출처를 시드 42로 섞어 절반씩 나눈 비교를 음성 대조군으로 사용합니다.
- 부적합/unknown/비적용 필드는 제외하며 필드별 유효 수·비율을 제공합니다. 제외 비율 차이 자체가 편향일 수 있습니다.
- 기존 레이블과 새 레이블의 차이는 별도 `label_changes`로 기록합니다. 같은 이미지의 레이블 수정은 시간적 데이터 드리프트로 부르지 않습니다.

현재 공통 시간축이 없습니다. 무신사 manifest에는 수집일이 없고 GS 원본의 수집 폴더만 확인되므로, 두 출처를 전/후 시점처럼 해석하지 않습니다. 통계량은 표본 독립성과 AI 레이블에 의존합니다. 유의한 분포 차이만으로 성능 저하나 인과관계를 확정하지 않습니다.

## 실행 및 조회

- `POST /api/jobs`에 `kind=labeling`, `dataset_id`를 보내면 고정 교사 작업을 접수합니다. 현재 비케이브 기준만 허용합니다. 새 버전은 성공한 작업에서만 등록됩니다.
- 웹의 워크스페이스 `AI 재레이블링` 버튼, 학습 모니터의 이미지 진행 수·취소·로그, 레이블 상세의 AI 원문에서 확인합니다.
- `GET /api/experiments/relabel-drift`: 실험 프로토콜, 작업 ID, 진행 및 최종 비교 결과.
- 드리프트 화면 상단에 동일 검증셋의 재학습 비교표를 표시합니다.
- 실행: `PYTHONPATH=. .venv/bin/python -u scripts/run_relabel_drift.py`. `.runtime/relabel-drift-experiment.json`에 작업 ID를 원자적으로 기록하며 재실행 시 기존 작업을 재사용합니다. 실패/취소된 GPU 작업을 성공한 것으로 바꾸거나 자동 재학습하지 않습니다.
- 이번 실험 조정 프로세스는 `datadrift-relabel-drift-20261027` systemd 사용자 작업입니다. 로그는 `journalctl --user -u datadrift-relabel-drift-20261027`. 완료 후 종료되는 작업이며 웹/API/워커의 상시 서비스와 구분합니다.
- GPU 실행은 기존 `datadrift-pipeline-worker`에서 순차 처리합니다. 웹/API/워커는 enabled/Restart=always/linger로 계속 실행합니다. 웹/API 재시작으로 GPU 작업을 끊지 않습니다.

실행 DB·원본 이미지·생성 레이블·모델 가중치와 개별 이미지가 포함된 스크린샷은 Git에 넣지 않습니다.

## 동일 검증셋 재학습 비교

기존 모델과 새 혼합 모델을 **같은 새 AI 정답·같은 검증 이미지 64장**으로 평가했습니다. 기존/새 2B·4B 혼합 학습 모두 같은 100장(무신사 60, GS SHOP 40)에 100 optimizer steps를 사용했고, 새 어댑터의 실제 가중치 변경·저장·재로딩을 확인했습니다. 전체 학습 1,190장에 대한 1 epoch가 아닙니다.

| 모델       | 전체 기존 → 재학습 | 무신사 기존 → 재학습 | GS SHOP 기존 → 재학습 |
| ---------- | -----------------: | -------------------: | --------------------: |
| Qwen3.5-2B |      42.1% → 66.8% |        45.2% → 69.5% |         38.2% → 63.3% |
| Qwen3.5-4B |      63.0% → 73.1% |        65.8% → 71.4% |         59.6% → 74.7% |

지표는 유효 속성별 일치도의 평균입니다. 각 출처의 평가 이미지는 32장입니다. 기존→새 모델의 JSON 파싱 오류는 두 모델 모두 0→0건, 허용값 위반은 2B 1→1건, 4B 3→0건입니다. 이전 변환 레이블·32장 평가에서 나온 73.4%/83.3%와 이 표를 직접 비교하면 안 됩니다.

현재 적재된 이미지의 긴 변은 무신사 1,000장 모두 384px, GS SHOP 651장 모두 130px입니다. 이는 이번 적재 파일의 특성이며 각 쇼핑몰 원본 이미지 품질 전체에 대한 평가가 아닙니다. 전체 RGB 히스토그램 JS는 0.0084로 0.1 미만이지만, 해상도 차이와 판독/제외율 차이가 속성 분석에 영향을 줄 수 있습니다.

핏·디테일은 출처 간 분포 차이 후보이면서 새 학생 모델의 교사 일치도도 낮습니다. 따라서 사람 검토와 모니터링의 우선 대상으로 볼 수 있습니다. 디테일은 정렬한 배열 전체 일치 기준이고, 소매 100%도 유효 18장에 한정된 결과입니다. 생산처·SKU 색상 코드는 유효 정답이 없어 평가하지 않았습니다.

## 출처 혼합 대조군과 불확실성

| 4B 학습 데이터 (각 100스텝) |  전체 | 무신사 32장 | GS SHOP 32장 | JSON 오류 | 허용값 위반 |

| 무신사만                    | 68.3% |       68.9% |        68.1% |         0 |           4 |

이 표의 지표는 앞선 표와 같은 속성별 일치도의 평균입니다. 고정된 학습 예산에서 GS SHOP을 포함한 혼합 학습이 GS SHOP 검증셋에서 더 높은 일치도를 보였습니다. 단일 시드·표본에 대한 탐색 결과이며 모든 운영 데이터로 일반화하지 않습니다.

별도로 이미지별 유효 속성 일치도의 평균을 계산하고 같은 이미지의 점수 차이에 대해 출처별 2,000회 paired bootstrap(시드 42, 백분위 95% 구간)을 적용했습니다. **아래는 이미지별 평균 지표이므로 위의 속성별 평균 표에서 단순히 뺀 값과 다릅니다.** 각 구간은 이미지 표본의 불확실성을 나타내며 교사 정답 오류나 다중 성능 비교의 불확실성은 보정하지 않았습니다.
